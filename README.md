E-Commerce Sales Analysis Using Python

Project Overview

This project analyzes e-commerce sales data using Python to understand business performance, sales trends, and customer purchasing behavior.

The project includes data cleaning, revenue calculation, sales analysis, and data visualization.

Objectives

- Analyze total revenue and order performance.
- Identify top-performing products and categories.
- Analyze monthly sales trends.
- Understand customer spending patterns.
- Compare sales across different cities.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- VS Code

Key Features

- Data cleaning and preprocessing
- Revenue calculation using Quantity × Unit Price
- Category-wise sales analysis
- Product-wise revenue analysis
- Monthly revenue trend visualization
- Top 5 customers analysis
- Top 5 products by revenue
- City-wise sales analysis
- Exporting cleaned data and summary reports to CSV files

Project Structure

- "ecommerce_sales_analysis.py" — Main Python analysis code
- "ecommerce_sales.csv" — Input dataset
- "outputs/" — Generated graphs and analysis reports
